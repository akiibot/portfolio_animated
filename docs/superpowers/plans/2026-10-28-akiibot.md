# Akiibot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an animated, helpful portfolio AI guide with unobtrusive shared abuse controls and bounded Gemini usage.

**Architecture:** A lazy React widget calls same-origin Node route handlers; only the server authenticates to Gemini 3.8 Flash on Vertex AI. Curated local facts and validated source IDs ground replies. Free managed Redis atomically enforces limits, duplicate suppression, concurrency and an estimated spending allowance, without storing conversations.

**Tech Stack:** Existing Next.js 16.4.3, React 19.3.1, TypeScript, Tailwind, Vitest and Playwright; Google Gen AI Node SDK, Google authentication library, Upstash Redis client, schema validation, Node crypto. Resolve current compatible package versions at implementation, record/pin chosen versions in the lockfile; no framework upgrades.

**Spec:** `docs/superpowers/specs/2026-10-28-akiibot-design.md`. Read it before this plan; it owns product behavior, limits, privacy and threat boundaries.

Define in `types.ts`:

```ts
type SourceLink = { id: string; label: string; href: string };
type HistoryTurn = { user: string; assistant: string };
type Mood = 'answering' | 'unsure' | 'happy';
type ModelReply = { answer: string; sourceIds: string[]; suggestions: string[]; mood: Mood };
type ChatRequest = { message: string; sessionToken: string; historyToken?: string; requestId: string };
type ChatReply = { answer: string; sources: SourceLink[]; suggestions: string[]; mood: Mood; historyToken: string; remainingMessages: number };
type ErrorCode = 'invalid_request' | 'forbidden' | 'session_expired' | 'rate_limited' | 'session_limit' | 'busy' | 'duplicate' | 'budget_exhausted' | 'unavailable' | 'timeout';
type ChatFailure = { code: ErrorCode; message: string; retryAfterSeconds?: number; fallbackLinks: SourceLink[] };
type TokenUsage = { inputTokens: number; billableOutputTokens: number };
```
